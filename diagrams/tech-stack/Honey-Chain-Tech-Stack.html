2Edge processing and the hive that listens

All noise cleaning is done in software on the ESP32, so the hardware stays cheap and small.

TechnologyPurposeStatus
Arduino C++ firmwareSensor loop, fan and heater control with hysteresis, local web dashboardBUILT
I²S digital audio bus24-bit digital sound from the mic chip, so the wires pick up no noisePLANNED
ESP-DSP: high-pass + low-pass filtersRemoves wind and machinery below 100 Hz, birds and hiss above 600 HzPLANNED
Rain gateSkips moments when rain drums on the roof (broadband noise)PLANNED
ESP-DSP: FFTSplits the 100–600 Hz buzz into its main frequencies (colony hum, queen piping)PLANNED
TensorFlow Lite Micro / Edge ImpulseQueen-status model running on the chip; only small feature packets are sent, never raw audioPLANNED
Sound pipeline: INMP441 mic → I²S → high-pass 100 Hz → low-pass 600 Hz → rain gate → FFT peaks + MFCC → AI model → "Queenless" / "Swarm risk" alert
